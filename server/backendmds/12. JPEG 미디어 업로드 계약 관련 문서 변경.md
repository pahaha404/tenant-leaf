#역할
너는 15년차 안드로이드 앱 개발자야. API 구현을 하는 것에 강점이 있어.

#요구사항
`공통 api 계약.md`, `openapi.yaml`, `도메인 규칙.md` 계약 문서를 수정해줘

#세부 요구사항
먼저 결정할 계약
MVP 기준으로 다음 값을 추천합니다.
- 형식: image/jpeg만 허용
- 크기: 사진당 최대 2MiB
- 임장 상태: ENDED인 임장에만 업로드 허용
- 한 번의 등록 요청: 최대 20장
- 업로드 URL 유효시간: 15분
- 자동 재시도: 최대 3회
- 중복 방지:
  - Android가 사진마다 clientMediaId UUID 생성
  - (inspectionId, clientMediaId)를 DB에서 유일하게 관리
  - 동일 사진을 재요청해도 새 데이터가 생기지 않게 처리
- 원본 영상, 갤러리 URI, 휴대전화 파일 경로는 서버로 보내지 않음
- 서버에 전달할 영상 관련 값:
  - sourceVideoId: 앱이 만든 익명 UUID
  - sourceVideoOffsetMs: 영상에서 추출한 시점
  - frameOrigin: POST_RECORDING_EXTRACTION
- 구역을 모르면 UNKNOWN
- 업로드 상태: PENDING, UPLOADING, UPLOADED, FAILED
- 분석 상태: NOT_REQUESTED, QUEUED, ANALYZING, COMPLETED, FAILED

필요한 API
아래 정도가 MVP에 적절합니다.
POST /api/v1/inspections/{inspectionId}/media/upload-requests
POST /api/v1/media/{mediaId}/upload-complete
POST /api/v1/media/{mediaId}/upload-retry
GET  /api/v1/inspections/{inspectionId}/media
GET  /api/v1/media/{mediaId}
업로드 등록 요청 예시:
{
  "clientMediaId": "앱에서 생성한 UUID",
  "zone": "BATHROOM",
  "contentType": "image/jpeg",
  "fileSize": 824531,
  "width": 1920,
  "height": 1080,
  "sourceVideoId": "영상 식별용 UUID",
  "sourceVideoOffsetMs": 12000,
  "frameOrigin": "POST_RECORDING_EXTRACTION"
}
응답 예시:
{
  "mediaId": "서버가 생성한 UUID",
  "uploadUrl": "객체 저장소 업로드 주소",
  "expiresAt": "2026-08-19T15:15:00+09:00",
  "uploadStatus": "PENDING"
}

## 실행 결과

- 상태: 계약 문서 및 OpenAPI 반영·검증 완료
- 공통 계약: 검토 초안 2.1로 갱신
- 등록 단위: 요청당 1~20장. 임장 전체 한도가 아님
- 업로드 URL: 15분 유효
- API: 등록, 완료, 재시도, 임장 미디어 목록, 미디어 상세
- 멱등성: 필수 `Idempotency-Key`, 다른 요청 재사용 시 `409 IDEMPOTENCY_KEY_CONFLICT`
- 검증: OpenAPI 문법 검사, Kotlin API·모델 생성, 생성 계약 테스트 통과
- 후속 범위: 객체 저장소·DB·Spring Boot API 구현, 임장당 전체 미디어 상한, 미디어 집합 확정 API
