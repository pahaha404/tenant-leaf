# Meta 안경 연동 작업 순서

1. SDK 접근 권한, 지원 Android 기기, Mock Device Kit 동작 여부를 기록한다.
2. Android 담당자와 구현 위치를 합의하고 앱이 사용할 최소 인터페이스로 SDK 의존성을 격리한다.
3. 연결·해제·배터리·권한 상태를 구현한다.
4. 안경 기본 고화질 영상 촬영, Meta AI 동반 앱을 통한 휴대전화 갤러리 가져오기 흐름을 실기기로 검증한다.
5. 기본 영상 녹화를 유지하면서 촬영 중 정지 사진을 생성할 수 있는지 검증한다. 녹화 중단·화질 저하·SDK 미지원이면 사후 추출 방식으로 전환한다.
6. 터치 입력과 TTS는 SDK 지원과 MVP 필요성이 확인된 뒤 별도 기능으로 구현한다.
7. Android 담당자에게 녹화·가져오기 상태값과 실패 코드 형식을 전달한다.
8. Mock Device Kit 확인과 실제 기기 확인을 구분해 기록한다. 실시간 스트리밍 AI 분석은 MVP에서 구현하지 않는다.

브랜치 예시: `feature/glass-connect`, `feature/glass-capture`, `feature/glass-tts`.
