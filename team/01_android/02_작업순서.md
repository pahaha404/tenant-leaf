# Android 프런트엔드 작업 순서

1. Android Studio와 JDK 21 설치를 확인한다.
2. 앱 모듈·공통 UI·화면 이동 구조를 먼저 만든다.
3. 매물, 방문 준비, 현장 영상 촬영, 영상 가져오기·JPEG 생성, 분석 진행, 보고서 화면을 차례대로 구현한다.
4. API가 아직 없으면 임시 데이터로 화면 상태를 검증하고, 임시임을 PR에 적는다.
5. API 계약이 정해지면 네트워크 연결과 오류·로딩·재시도 상태를 붙인다.
6. AI 관찰 결과는 `확인 필요`와 근거 사진으로 표시한다.
7. 기능 단위로 에뮬레이터 또는 실제 기기에서 확인하고 PR을 만든다.

원본 영상은 휴대전화 갤러리에만 보관하고 서버에 업로드하지 않는다. 촬영 완료 영상의 고정 3초 구간마다 JPEG 후보를 만들고 가장 선명한 한 장을 선택한다. 촬영 중 정지 사진 생성은 실기기 검증 후 선택적으로만 사용한다.

Meta 안경 기능은 구현 위치와 인터페이스를 담당자와 먼저 합의해 격리한다. 아직 존재하지 않는 SDK API나 폴더를 있다고 가정하지 않는다.
