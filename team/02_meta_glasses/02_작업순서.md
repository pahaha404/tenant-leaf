# Meta 안경 연동 작업 순서

1. SDK 접근 권한, 지원 Android 기기, Mock Device Kit 동작 여부를 기록한다.
2. `glass-adapter`에 앱이 사용할 최소 인터페이스를 먼저 정의한다.
3. 연결·해제·배터리·권한 상태를 구현한다.
4. 촬영 시작·중지·사진 수신을 구현한다.
5. 터치 입력과 TTS를 구현한다. 음성 안내와 별도 녹음은 동시에 무리하게 사용하지 않는다.
6. Android 담당자에게 상태값과 실패 코드 형식을 전달한다.
7. Mock Device Kit 확인과 실제 기기 확인을 구분해 기록한다.

브랜치 예시: `feature/glass-connect`, `feature/glass-capture`, `feature/glass-tts`.
