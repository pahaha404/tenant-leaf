# 세입세잎 UI 페이지 · 버튼 구조 (MVP)

## 1. 목적

세입세잎은 사용자가 방을 보면서 휴대폰을 계속 보지 않아도, 스마트 글라스와 음성 안내를 따라 점검하고 사진·확인 결과를 매물별로 정리하는 임장 보조 앱이다.

이 문서는 화면 구현과 pen.dev 디자인의 기준이다. AI는 하자를 확정하지 않고 촬영 종료 후 관찰 내용과 근거 사진을 제안하며, 사용자는 관찰을 열람하거나 리포트에서 제외할 수 있다.

## 2. MVP 핵심 사용자 흐름

```text
앱 시작
├─ 첫 사용자
│  ├─ 온보딩
│  ├─ 촬영·녹음·개인정보 안내 동의
│  ├─ 튜토리얼 선택 또는 건너뛰기
│  └─ 로그인 / 테스트 계정 시작
└─ 기존 사용자
   └─ 홈
      ├─ 새 매물 등록
      │  └─ 매물 상세 → 점검 준비
      ├─ 기존 매물 선택
      │  └─ 매물 상세 → 점검 준비
      ├─ 최근 임장 이어가기
      │  └─ 현장 영상 촬영 또는 분석 진행
      ├─ 리포트 보기
      │  └─ 매물 리포트 → 매물 비교
      └─ 내 정보 / 설정

점검 준비
├─ 스마트 글라스 연결 및 배터리 확인
├─ 카메라·마이크·위치 권한 확인
├─ 촬영 사실 안내 확인
└─ 점검 시작
   └─ 현장 영상 촬영
      ├─ 안경 기본 고화질 영상 녹화
      ├─ 연결·배터리·촬영 시간·클립 수 확인
      └─ 촬영 종료
         └─ 영상 가져오기·분석 준비
            ├─ 휴대전화 갤러리 가져오기 확인
            ├─ 촬영 중 생성 사진 또는 완료 영상의 JPEG 추출
            └─ JPEG 업로드
               └─ 분석 진행
                  └─ 증거 사진 검토
                     └─ 리포트
                        ├─ 수정
                  ├─ 매물 상세로 돌아가기
                  └─ 다른 매물과 비교
```

### 면적 단위 전환

- 매물 등록·수정·상세·비교 화면의 면적 옆에 `㎡ / 평` 전환 버튼을 제공한다.
- `1평 = 3.305785㎡`를 사용하고 화면에는 소수점 둘째 자리까지 표시한다.
- 사용자가 평으로 입력하면 앱 내부에서 ㎡로 변환하여 API의 `areaSquareMeters`로 전송한다.
- API 응답의 ㎡ 값을 기준으로 표시 단위만 바꾸며 평 값을 매물 데이터에 중복 저장하지 않는다.
| P0 | 18 내 정보 | 계정, 연결 기기, 데이터 사용량을 관리한다. | 프로필 수정, 기기 관리, 설정 | 설정 |
| P0 | 19 설정·개인정보 | 안내, 촬영·녹음, 위치, 알림, 데이터 삭제를 관리한다. | 토글 변경, 데이터 삭제, 로그아웃, 계정 삭제 | 이전 화면 |

## 4. 현장 영상 촬영 화면의 가지형 버튼 구조

```text
현장 영상 촬영
├─ 상단 상태
│  ├─ 안경 연결 상태 → 기기 상태 상세
│  ├─ 배터리 → 기기 상태 상세
│  └─ 촬영 종료 → 종료 확인
├─ 녹화 상태
│  ├─ 촬영 시간
│  └─ 생성된 영상 클립 수
├─ 핵심 행동
│  ├─ 녹화 시작·재개
│  └─ 새 클립 시작
├─ 보조 행동
│  ├─ 녹음 → 녹음·STT
│  └─ 일시정지 → 현재 클립 종료 및 촬영 대기
└─ 종료 확인
   ├─ 계속 촬영하기 → 현장 영상 촬영
   └─ 촬영 완료 → 영상 가져오기·분석 준비
```

## 5. 하단 내비게이션

| 탭 | 연결 화면 | 탭을 눌렀을 때 |
| --- | --- | --- |
| 홈 | 홈 | 진행 중인 점검이 있으면 `점검으로 돌아가기`를 우선 표시한다. |
| 점검 | 매물 목록·지도 또는 현장 영상 촬영 | 진행 중인 점검이 있으면 현장 영상 촬영으로, 없으면 매물 선택으로 이동한다. |
| 리포트 | 최근 리포트 목록 | 최근 리포트와 처리 중인 리포트를 표시한다. |
| 내 정보 | 내 정보 | 계정·기기·설정 진입을 제공한다. |

## 6. 공통 상태와 규칙

| 상태 | 사용자에게 보일 내용 | 가능한 행동 |
| --- | --- | --- |
| 기기 연결 실패 | 연결 실패 원인과 현재 데이터가 보존됨을 안내한다. | 다시 연결, 휴대폰으로 계속 |
| 영상 가져오기 대기 | Meta AI 동반 앱에서 휴대전화 갤러리로 가져오기가 필요한 상태를 안내한다. | 가져오기 확인, 다시 확인 |
| JPEG 생성 실패 | 촬영 완료 영상은 유지하고 실패한 클립과 재시도 방법을 표시한다. | 다시 추출, 해당 클립 제외 |
| 권한 거부 | 필요한 권한과 이유를 설명한다. | 설정으로 이동, 나중에 |
| AI 관찰 있음 | AI의 중립적 관찰과 근거 사진을 보여 준다. | 사진 보기, 열람 완료, 리포트에서 제외 |
| 사진 업로드 실패 | 실패한 사진 목록과 재시도 가능 여부를 표시한다. | 다시 시도, 제외하고 계속 |
| 리포트 처리 중 | 사진·AI·STT·리포트별 진행 상태를 보여 준다. | 백그라운드로 이동, 다시 시도 |
| 촬영 종료 확인 | 저장된 영상 클립 수와 촬영 시간을 요약한다. | 계속 촬영하기, 촬영 완료 |

## 7. 디자인 작업 순서

1. `01 온보딩`, `05 홈`, `07 매물 등록`을 현재 디자인 톤으로 확정한다.
2. `09 점검 준비`, `10 현장 영상 촬영`, `11 영상 가져오기·분석 준비`, `12 분석 진행`을 이어서 디자인한다.
3. `13 증거 사진 검토`, `15 처리 현황`, `16 임장 리포트`, `17 매물 비교`를 디자인한다.
4. `18 내 정보`, `19 설정·개인정보`와 오류·빈 화면을 디자인한다.
5. 각 화면을 Android Jetpack Compose로 하나씩 구현하고 실제 기기 또는 에뮬레이터에서 확인한다.

## 8. pen.dev에 옮길 때의 요청 단위

한 번에 전체 앱을 생성하지 않는다. 화면 1~2개씩, 기존 디자인 시스템을 유지하는 요청으로 추가한다.

예시:

```text
현재 세입세잎 디자인 시스템과 01 온보딩, 02 홈, 03 매물 등록의 색상·폰트·카드·버튼 규칙을 유지해줘.
04 점검 준비와 05 현장 영상 촬영, 06 영상 가져오기·분석 준비 화면을 오른쪽에 추가해줘.
기기 연결 실패, 배터리, 권한 확인, 녹화 시간, 영상 클립 수, 촬영 종료, 갤러리 가져오기, JPEG 생성·업로드 상태를 포함해줘. 촬영 중 AI 분석 결과는 표시하지 마.
기존 프레임은 삭제하거나 수정하지 마.
```
