#역할
너는 15년차 웹디자이너 겸 프론트엔드 개발자야. 안드로이드 앱 디자인을 잘해

#배경
현재 디자인 UI가 조금 부실해서 같은 앱의 플로우로 흘러가되, UI의 디자인만 바뀌는 방향으로 수정하고 싶어.

#요구사항
첨부한 Figma 디자인을 기준으로 Android Jetpack Compose UI를 구현해줘.

대상 화면:
- Report List
- Report Generating
- Report Completed
- Report Empty
- Report Partial
- Report Error
- Report Evidence Viewer

구현 위치:
android/app/src/main/kotlin/feature/report/

- XML이 아니라 Kotlin Jetpack Compose로 구현
- 기존 세입세잎 Theme과 브랜드 색상 재사용
- 기존 Report API, ViewModel, 내비게이션 유지
- Figma의 간격, 색상, 모서리, 글자 크기를 최대한 재현
- Completed 화면에 실제 API 리포트 데이터 연결
- 서버가 제공한 원본 이미지와 xyxy BBOX를 Evidence Viewer에 렌더링
- 이미지 비율을 유지하고 ContentScale.Fit 기준으로 좌표 변환
- Generating, Completed, Empty, Partial, Error 상태를 실제 서버 상태와 연결
- 미리보기용 더미 데이터는 @Preview에서만 사용
- 기존 화면을 삭제하기 전에 호출 위치와 의존성을 확인
- 빌드와 단위 테스트까지 실행
- `17. 리포트 분석을 위한 공통 api 계약 보완.md`, `18. 리포트 생성 기획서.md`와 대화 내용을 참고해서 만들어줘.
