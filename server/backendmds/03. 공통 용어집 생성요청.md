#역할
너는 15년차 앱 개발자야. 특히 백엔드를 전문적으로 다뤄.

#배경
프로젝트 내 프론트엔드와 백엔드에서 공통으로 사용할 공통 용어집을 만들어야해.

#요구사항
1. 현재 프로젝트에서 쓰일 공통용어집 단어들을 아래와 비슷하게 구축하는 `공통용어집.md`를 만들어줘. 비개발자도 이해하기 쉽게 아래처럼 직관적으로 만들어줘.
2. 아래 단어 말고도 추가할 사항들이 있으면 추가해줘. 의미가 모호한 단어들이 있을 수 있으니 명확하게 표현할 수 있도록 만들어줘.
3. 나중에 언제든지 단어의 의미를 확대하거나 축소할 수도 있는 상황이 발생할 수도 있음을 인지해서 나중에 수정할 때도 오류가 없도록 만들어줘.
4. 나중에 수정되는 사항이 있으면 수정되었다는 표시를 알기 쉽게끔 단어에 빗금을 치고서 수정해줘.
5. 하자 종류 용어는 데이터 분석을 다루는 분이 먼저 분류를 하고나서 기입을 하려고 하니 지금은 공란으로 놓아줘.

한글 용어	영문 표준명	설명
사용자	user	서비스를 사용하는 회원
매물	property	사용자가 방문하는 임대 주택
임장	inspection	특정 매물을 한 번 점검하는 행위
체크리스트	checklist	임장 중 확인할 항목
촬영 프레임	frame	AI 분석을 위해 추출한 이미지
AI 탐지	detection	AI가 이미지에서 발견한 하자
하자 종류	label	mold, water_stain, crack 등
신뢰도	confidence	AI 탐지 신뢰도, 0~1
바운딩 박스	bbox	하자가 발견된 이미지 영역
메모	note	사용자가 남긴 기록
임장 리포트	report	임장 종료 후 생성되는 결과
기기	device	스마트글래스 등의 촬영 장치
