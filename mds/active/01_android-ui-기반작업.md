# Android UI 기반 작업

상태: Draft

담당 역할: `android`

## 목표

`design/UI/UI.pen`의 확정 디자인 시스템과 핵심 사용자 흐름을 기준으로 Android Jetpack Compose UI의 첫 기반을 만든다.

## 수정 범위

- 색상, 타이포그래피, 간격, 버튼 스타일을 공통 Compose 디자인 시스템으로 정의
- 통합 로그인·이메일 회원가입·동의·권한 설정 화면의 정적 UI 구현
- 홈, 매물 목록·상세, 리포트, 내 정보 화면의 정적 UI 구현
- 하단 내비게이션과 기본 화면 이동 상태 구현

## 하지 않는 것

- Meta 글라스 SDK 실제 연결
- 실제 서버·AI API 연결
- 실제 매물·미디어 데이터 저장

## 완료 기준

- [ ] Android 앱이 빌드된다.
- [ ] 인증, 홈, 매물, 리포트 기본 화면을 에뮬레이터에서 확인한다.
- [ ] 디자인 파일과 차이가 큰 항목을 기록한다.

## 검증 방법

- Android 에뮬레이터 또는 실기기에서 인증·홈·매물·리포트 화면과 하단 내비게이션을 직접 확인
