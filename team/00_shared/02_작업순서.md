# 전원 공통 작업 순서

## 매일 시작

```powershell
git switch develop
git pull origin develop
git switch -c feature/<영역>-<기능>
```

브랜치 예시: `feature/android-visit-screen`, `feature/glass-connect`, `feature/api-property`, `feature/ai-image-quality`.

## 작업 중

1. `공용 Task.md`와 해당 역할 Task 문서에서 진행할 항목을 확인합니다.
2. 다른 역할에 API·데이터·화면 변경을 요청해야 하면 먼저 단체 채팅과 PR에 알립니다.
3. 변경은 작게 나누고, 관련 파일만 커밋합니다.

## 작업 종료

```powershell
git status
git add <관련 폴더 또는 파일>
git commit -m "feat(영역): 변경 내용"
git push -u origin feature/<영역>-<기능>
```

GitHub에서 `feature/* -> develop` Pull Request를 만듭니다. 실제 검증이 끝난 항목만 `[x]`로 표시합니다.
