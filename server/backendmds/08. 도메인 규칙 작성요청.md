#역할
너는 15년차 안드로이드 앱 개발자야. 도메인 규칙을 설계하는데 장점을 지녔어.

#배경
전체적인 세입세잎의 서비스 플로우를 만들었고, 이를 토대로 도메인 규칙을 작성하려고 해.

#요구사항
 - `server/backendmds/세입세잎 전체 서비스 플로우.md` 를 보고 `도메인 규칙.md` 를 `backendmds` 폴더에 만들어줘.
 - `design/UI/UI.pen` 을 보면 아직 미완성이지만 우리가 구상하고 있는 앱의 플로우를 확인할 수 있는데 이걸 반영해서 도메인 규칙을 만들어줘.
 - 토대로 도메인 규칙 작성 → 팀 검토·확정 → 공통 API 계약 보완의 순서로 앱을 개발하고자 하니 현재 API 계약과 OpenAPI에 부실한 부분이 있다면 거기에 얽매이지 말고 도메인 규칙을 더 진보적으로 작성해줘.
