# 요구사항

우리 팀 데이터 분석 담당자가 분류한 하자 종류를 `공통용어집.md`에 추가한다.
기존 12개 라벨에 `other(기타)`를 추가하여 총 13개 라벨로 관리한다.

# 하자 종류

```yaml
path: .
train: images/train
val: images/val
nc: 13
names:
  0: crack 균열
  1: mold 곰팡이
  2: peeling _도장/벽지 박리
  3: waterdamage 누수/침수 흔적
  4: tiledamage 타일 파손
  5: hole _타공/구멍
  6: tilecrack 타일 균열
  7: paintdrips 페인트 흘러내림
  8: pinhole 핀홀
  9: surfacedefect 면불량
  10: stain _오염/얼룩
  11: trowelmark 흙손 자국
  12: other 기타
```

# `other(기타)` 추가 기준

- 영문 표준 라벨은 소문자 `other`, 클래스 ID는 `12`, 한글 표시명은 `기타`로 사용한다.
- 모델이 하자 기준에 부합하는 후보를 탐지했지만 기존 클래스 ID `0`~`11` 중 어떤 종류인지 구체적으로 분류하지 못한 경우 `other`로 분류한다.
- `other`는 배경, 하자 후보 없음, 단순 분석 실패를 의미하지 않는다.
- `other` 결과도 확정된 하자 판정이 아니라 사용자가 근거 사진을 확인해야 하는 관찰 후보로 다룬다.
- 기존 클래스 ID `0`~`11`은 학습 데이터와 모델 출력의 호환성을 위해 변경하거나 재사용하지 않는다.
