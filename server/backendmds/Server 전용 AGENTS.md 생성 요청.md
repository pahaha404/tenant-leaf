server/AGENTS.md를 작성해줘.

루트 AGENTS.md의 공통 규칙을 그대로 따르되, server 폴더 안에서 작업하는
백엔드 개발자와 AI 코딩 도구가 지켜야 할 세부 규칙을 추가해줘.

다음 내용을 포함해줘.

1. 기술 환경
- JDK 21 LTS
- Kotlin
- Spring Boot 4.1
- Gradle Wrapper
- PostgreSQL 17
- Spring Data JPA
- Flyway
- OpenAPI Generator
- JUnit 5

2. 서버 폴더 책임
- server/api는 인증, 매물, 임장, 체크리스트, 프레임 업로드와 AI 결과 조회를 담당한다.
- server/ai-worker는 무거운 사진 분석, STT, 비동기 작업을 담당한다.
- API의 HTTP 요청 처리 중에 무거운 AI 추론을 직접 실행하지 않는다.

3. API 계약 규칙
- 공통 OpenAPI 명세를 API 요청·응답 타입의 기준으로 사용한다.
- 자동 생성된 build/generated 코드에는 직접 수정하지 않는다.
- 요청·응답 필드나 상태값을 변경하면 OpenAPI, 계약 문서, 서버 구현과 테스트를 같은 변경에서 수정한다.
- 미확정된 API 필드나 enum 값을 임의로 추가하지 않는다.

4. Kotlin·Spring 구현 규칙
- Controller는 HTTP 요청과 응답 변환만 담당한다.
- 비즈니스 규칙은 Service에 작성한다.
- 데이터 접근은 Repository에 둔다.
- JPA Entity를 API 응답으로 직접 반환하지 않고 생성된 OpenAPI 모델로 변환한다.
- 트랜잭션 경계를 Service 계층에 둔다.
- Kotlin의 null 가능성을 명확하게 표현하고 강제 언래핑(!!)을 피한다.
- 생성자 주입을 사용하고 필드 주입을 사용하지 않는다.

5. 데이터베이스 규칙
- DB 구조 변경은 새 Flyway 마이그레이션 파일로 적용한다.
- 이미 적용된 마이그레이션 파일은 수정하거나 삭제하지 않는다.
- 금액은 원 단위 정수로 저장한다.
- 면적은 제곱미터를 기준값으로 저장하며 평 값을 중복 저장하지 않는다.
- 사진 원본은 PostgreSQL에 저장하지 않고 접근 제어된 객체 저장소에 둔다.

6. 보안·개인정보 규칙
- API 키, 비밀번호, 실제 주소, 계정 정보와 촬영 자료를 Git에 커밋하지 않는다.
- 비밀번호, 토큰, DB 연결 문자열과 개인정보를 로그에 출력하지 않는다.
- 사용자가 소유하지 않은 매물이나 임장 자료에 접근하지 못하도록 권한을 검증한다.
- 부동산 연락처는 사용자가 직접 작성한 참고 정보이며 서버가 정확성을 보증하지 않는다.

7. AI 관련 규칙
- AI 결과는 하자 또는 안전 상태의 확정 판정으로 표현하지 않는다.
- Detection은 근거 프레임이 있는 확인 필요 관찰 후보로 처리한다.
- 체크리스트 최종 상태는 사용자의 확인이 있을 때만 변경한다.
- 모델 버전, 근거 frameId, confidence와 사용자 검토 상태를 기록한다.

8. 오류 처리 규칙
- API는 공통 ErrorResponse 형식을 사용한다.
- 사용자가 이해할 message와 클라이언트가 분기할 안정적인 code를 구분한다.
- 내부 예외 메시지와 스택 트레이스를 API 응답으로 노출하지 않는다.

9. 검증 규칙
- 변경 후 OpenAPI 문법 검사, Kotlin 코드 생성, 컴파일과 테스트를 실행한다.
- 기본 검증 명령은 server/api에서 `.\gradlew.bat clean test`이다.
- PostgreSQL 연동 테스트 전 Docker 컨테이너가 healthy인지 확인한다.
- 구현과 필요한 검증이 모두 끝난 작업만 완료 처리한다.

10. Git 규칙
- main과 develop에 직접 푸시하지 않는다.
- feature/api-* 브랜치에서 작업하고 develop 대상 PR을 만든다.
- 커밋 전 git status와 diff를 확인하고 관련 파일만 추가한다.
- 다른 담당자의 변경이나 사용자 파일을 임의로 삭제하지 않는다.

루트 AGENTS.md와 내용을 불필요하게 반복하지 말고,
서버 작업에서 실제 판단 기준이 되는 내용 위주로 간결하게 작성해줘.
