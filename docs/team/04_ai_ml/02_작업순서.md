# AI·ML 작업 순서

1. 사진에서 관찰 가능한 P0 라벨을 확정한다. 예: 균열 의심, 누수·변색 의심, 곰팡이 의심, 흐림, 어두움, 가림, 중복.
2. 라벨 기준과 `확인 필요` 표현을 문서화한다.
3. 데이터 수집 근거, 동의·사용 범위, 비식별 처리, 보유·파기 기한을 데이터셋 메타데이터에 기록한다.
4. 원본 데이터는 접근 제어된 외부 저장소에 두고, GitHub에는 버전과 식별자만 기록한다.
5. 같은 주택·방문 세션 사진이 학습과 평가에 섞이지 않게 분할한다.
6. 먼저 AI 작업자의 입력·출력 JSON과 실패 응답을 구현한다.
7. 모델은 관찰 후보, 신뢰도, 근거 미디어 ID, 모델 버전을 반환한다.
8. 평가 결과는 라벨별 재현율·오탐·미탐과 실제 현장 테스트 결과를 함께 기록한다.

브랜치 예시: `feature/ai-image-quality`, `feature/ai-observation-contract`, `feature/ml-dataset-manifest`.
