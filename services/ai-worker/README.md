# ai-worker

Kotlin 기반 비동기 AI 분석 워커 폴더입니다.

## 책임

- 영상에서 분석용 프레임 추출
- 곰팡이·변색·누수 흔적·균열·파손 후보 탐지
- 음성 파일을 텍스트로 변환
- 음성 메모를 체크리스트 항목과 상태 후보에 연결
- 분석 결과·신뢰도·안내 문구를 API 서버에 저장

## 구현 방식

- Kotlin + Spring Boot Worker 또는 Kotlin Ktor Worker
- Redis 큐에서 분석 작업을 수신
- STT·TTS·이미지 분석은 한국어 지원 외부 AI API 또는 별도 모델 서버 호출
- 모델 추론 코드를 직접 운영해야 할 시점에는 별도 모델 서버를 추가하되, Android 앱과 API 서버는 Kotlin으로 유지

## 주의

AI 결과는 하자 확정이 아니라 `확인 필요` 후보로만 반환합니다.
