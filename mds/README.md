# MDS 작업 요청서

`mds/`는 코드나 디자인을 변경하기 전에 읽는 짧은 작업 명세 폴더입니다.

## 폴더

- `active/`: 지금 진행 중인 요청서
- `completed/`: 구현·검증까지 끝난 요청서
- `templates/`: 새 요청서 작성용 템플릿

## 사용 규칙

1. 새 작업은 `active/`에 번호와 기능명을 넣어 작성한다.
2. 요청서에는 담당 역할, 수정 범위, 완료 기준, 검증 방법을 쓴다.
3. 완료된 요청서는 결과를 갱신한 뒤 `completed/`로 이동한다.
4. 체크리스트의 완료 상태는 `Tasks/`에서, 상세 요구사항은 `mds/`에서 관리한다.
