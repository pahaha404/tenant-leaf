# Android 프런트엔드 시작

## 담당 범위

- 로그인·매물·임장·구역·관찰·근거 사진·보고서·설정 화면
- Android 권한, 화면 상태, 네트워크 결과 표시
- 사용자가 AI 관찰 결과와 근거 사진을 확인하고 검토 상태를 변경하는 흐름

## 먼저 읽을 문서

1. `server/backendmds/도메인 규칙.md`
2. `team/00_shared/공통 api 계약.md`
3. `server/shared-types/openapi/openapi.yaml`
4. `server/technical/architecture.md`
5. 최신 결정과 충돌하지 않는 `design/` 산출물

현재 구현된 서버 연결 범위는 매물 CRUD다. Media·Observation·Report의 정확한 HTTP API는 공통 계약에서 확정되기 전까지 임의로 만들거나 호출하지 않는다.
