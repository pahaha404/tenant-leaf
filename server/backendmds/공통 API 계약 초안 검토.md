project가 필요한지, 매물과 어떤 관계인지
-> project를 제외하고 사용자 → 매물 → 임장으로 시작

체크리스트 상태값 4개가 적절한지
- unchecked — 아직 사용자가 확인하지 않음
- normal — 사용자가 특이사항 없음을 확인함
- needs_review — 문제 가능성이 있어 추가 확인이 필요함
- not_applicable — 해당 매물에는 적용되지 않는 항목


AI의 12개 라벨과 bbox 형식이 실제 모델 출력과 맞는지
