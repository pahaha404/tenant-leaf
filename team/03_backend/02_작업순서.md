# 백엔드 작업 순서

1. JDK 21과 Docker Desktop을 설치·확인한다.
2. API 서비스의 빌드·테스트·로컬 실행 기준을 만든다.
3. PostgreSQL과 Redis의 로컬 실행 환경을 만든다.
4. 매물·임장·Media·MediaAnalysis·Observation·근거 미디어·Report 데이터 모델을 확정된 계약 범위부터 구현한다.
5. Android가 먼저 필요한 API부터 작은 단위로 구현한다.
6. 업로드 URL 발급과 미디어 메타데이터 저장을 구현한다.
7. AI 작업 요청·상태 조회·결과 조회 API를 구현한다.
8. API 명세와 공통 계약을 함께 갱신하고 테스트한다.

브랜치 예시: `feature/api-property`, `feature/api-media-upload`, `feature/api-ai-job`.
