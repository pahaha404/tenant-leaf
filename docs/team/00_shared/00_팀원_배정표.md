# 팀원 배정표

팀원 GitHub 아이디가 정해지면 아래 표만 채웁니다. 코드 파일명이나 폴더명에 사람 이니셜을 넣지 않습니다.

| 역할 | 담당자 이름 | GitHub 아이디 | 주 작업 폴더 | 백업 담당 |
| --- | --- | --- | --- | --- |
| Android 프런트엔드 | 미정 | `@github-id` | `apps/android/tenantleaf`, `apps/android/feature`, `apps/android/core` | 미정 |
| Meta 안경 연동 | 미정 | `@github-id` | `apps/android/glass`, `packages/glass-adapter` | 미정 |
| 백엔드 | 미정 | `@github-id` | `services/api` | 미정 |
| AI·ML | 미정 | `@github-id` | `services/ai-worker`, `ml` | 미정 |
| PM·통합 | 미정 | `@pahaha404` | `docs`, `design`, 전체 통합 | 미정 |

배정 후 `.github/CODEOWNERS.example`의 예시 아이디도 실제 아이디로 바꾸고 파일명을 `CODEOWNERS`로 변경합니다.
