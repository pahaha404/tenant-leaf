# 팀 작업실

이 폴더는 사람 이름이 아니라 역할을 기준으로 나눈 팀 작업실입니다. 담당자가 바뀌어도 폴더와 문서는 유지합니다.

## 시작 순서

1. `00_shared/00_팀원_배정표.md`에서 자신의 담당 역할을 확인합니다.
2. 맡은 역할 폴더의 `01_시작.md`를 읽습니다.
3. `02_작업순서.md` 순서대로 작업합니다.
4. `03_Task.md`에서 자신이 실제로 완료·검증한 항목만 `[x]`로 바꿉니다.
5. 기능 단위로 Pull Request를 만들어 `develop`으로 보냅니다.

## 폴더 안내

| 폴더 | 담당 |
| --- | --- |
| `00_shared` | 전원이 공통으로 따르는 규칙 |
| `01_android` | Android 화면·상태·권한·체크리스트 |
| `02_meta_glasses` | Meta 안경 SDK, 촬영, 연결, TTS |
| `03_backend` | API, DB, 업로드, 작업 요청 |
| `04_ai_ml` | AI 추론, 학습·평가 코드, 데이터셋 메타데이터 |
| `05_pm_integration` | 범위, 화면 기준, 통합, QA, 데모 |

루트 `Task.md`는 프로젝트 전체의 일정·완료 기록용입니다. 역할별 `03_Task.md`는 각 담당자의 세부 실행 목록입니다.
