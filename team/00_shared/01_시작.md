# 전원 공통 시작 안내

## 처음 한 번

1. GitHub 초대를 수락합니다.
2. [CONTRIBUTING.md](../../../CONTRIBUTING.md)와 [AGENTS.md](../../../AGENTS.md)를 읽습니다.
3. 저장소를 복제하고 `develop` 브랜치로 이동합니다.

```powershell
git clone https://github.com/pahaha404/tenant-leaf.git
cd tenant-leaf
git switch develop
git pull origin develop
```

4. 자신의 역할 폴더 `01_시작.md`를 읽습니다.
5. 단체 채팅에 `feature/<영역>-<기능> 작업 시작`이라고 알립니다.

## 공통 금지

- `main`, `develop`에 직접 푸시하지 않기
- 실제 현장 사진·영상·음성·비밀키 업로드하지 않기
- 다른 사람 파일을 확인 없이 삭제·되돌리지 않기
- 코드 파일명에 사람 이름·이니셜 넣지 않기
