# 디자인 자료 안내

## 현재 작업 파일

- `untitled.pen`: 현재 pen.dev에서 열어 작업 중인 세입세잎 UI 디자인 파일

작업 중인 파일이므로 pen.dev와 VS Code에서 모두 닫은 뒤에만 `세입세잎.pen` 등으로 이름을 바꾼다.

## reference

- `세입세잎.pdf`: 색감·캐릭터·레이아웃 참고용 원본 PDF

## assets/generated

- `brand-character.png`: 디자인에 사용한 캐릭터 이미지

## previews/reference-pdf

- PDF에서 추출한 캐릭터·팔레트·레이아웃 미리보기

## archive

- `pencil-welcome-backup.pen`: 초기 welcome 디자인의 백업 파일

## 정리 규칙

- 새로운 원본 디자인 파일은 이 폴더의 최상단에 둔다.
- 외부 참고 자료는 `reference/`에 둔다.
- 재사용할 이미지·SVG는 `assets/`에 둔다.
- 결과 확인용 PNG는 `previews/`에 둔다.
- 더 이상 편집하지 않는 이전 디자인은 `archive/`에 둔다.
