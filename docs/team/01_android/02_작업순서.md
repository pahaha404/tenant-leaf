# Android 프런트엔드 작업 순서

1. Android Studio와 JDK 21 설치를 확인한다.
2. 앱 모듈·공통 UI·화면 이동 구조를 먼저 만든다.
3. 매물, 방문 준비, 실시간 점검, 체크리스트, 보고서 화면을 차례대로 구현한다.
4. API가 아직 없으면 임시 데이터로 화면 상태를 검증하고, 임시임을 PR에 적는다.
5. API 계약이 정해지면 네트워크 연결과 오류·로딩·재시도 상태를 붙인다.
6. AI 관찰 결과는 `확인 필요`와 근거 사진으로 표시한다.
7. 기능 단위로 에뮬레이터 또는 실제 기기에서 확인하고 PR을 만든다.

Meta 안경 SDK 직접 호출은 `apps/android/glass/` 담당자와 합의한 인터페이스를 통해서만 사용한다.
