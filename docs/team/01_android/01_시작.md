# Android 프런트엔드 시작

## 담당 범위

- 로그인·매물·방문 세션·체크리스트·보고서·설정 화면
- Android 권한, 화면 상태, 네트워크 결과 표시
- 사용자가 AI 관찰 결과를 확인하고 최종 체크 상태를 선택하는 흐름
